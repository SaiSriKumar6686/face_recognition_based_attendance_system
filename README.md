# Face Attendance System
### CCTV-based face recognition with continual learning

---

## Project overview

Three-phase attendance system that starts with 5–10 seed photos per student,
generates 200–500 synthetic training images, trains AdaFace IR-18, deploys
for live CCTV inference, and continuously self-improves using verified
attendance crops.

## Quick start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Clone AdaFace

```bash
mkdir -p third_party
git clone https://github.com/mk-minchul/AdaFace.git third_party/adaface
```

### 3. Add seed images

```
data/seed_images/
    student_001/    ← student ID matches DB
        img1.jpg
        img2.jpg
    student_002/
        ...
```

### 4. Build synthetic dataset

```bash
python scripts/dataset_builder.py
```

### 5. Train

```bash
python scripts/train_bootstrap.py
```

### 6. Export ONNX

```bash
python scripts/export_onnx.py
```

### 7. Enroll students into FAISS

```bash
python -m src.enrollment.enroll_student --all
```

### 8. Run the full system

```bash
python scripts/run_system.py --source 0 --fps 2.0 --port 5000
```

Admin dashboard: http://localhost:5000

## Configuration

All tunable parameters are in `configs/config.yaml`.
Key settings:

| Key | Default | Description |
|-----|---------|-------------|
| `augmentation.target_samples_per_identity` | 300 | Synthetic images per student |
| `inference.high_confidence_threshold` | 0.65 | Auto-mark attendance above this |
| `inference.soft_threshold` | 0.30 | Queue for review above this |
| `continual_learning.retrain_trigger_n` | 20 | New samples to trigger fine-tune |
| `continual_learning.ewc_lambda` | 5000 | EWC regularisation strength |

## Technology stack

| Component | Tool |
|-----------|------|
| Face detection | InsightFace RetinaFace |
| Face recognition | AdaFace IR-18 (PyTorch) |
| CCTV degradation sim | OpenCV + albumentations |
| Training | PyTorch, AdaFace loss |
| Continual learning | EWC + synthetic replay buffer |
| CPU inference | ONNX Runtime |
| Embedding store | FAISS FlatIP + SQLite |
| Quality scoring | BRISQUE (image-quality) |
| Web dashboard | Flask + Jinja2 |
